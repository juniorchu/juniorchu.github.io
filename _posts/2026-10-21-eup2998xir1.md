안녕하세요! 대만 EUTECH Microelectronics 국내 공식 대리점 (주)제이씨코포레이션입니다.

오늘 소개해 드릴 제품은 대형 LCD TV, 상업용 키오스크(Kiosk), 산업용 모니터 및 디지털 사이니지 백라이트 구동에 최적화된 **4채널 고출력 White LED Driver IC EUP2998XIR1** 입니다.

본 제품은 MPS社의 MP3398EGF와 Pin-to-Pin 핀투핀 호환을 제공하며, Silergy社의 SY7728과 기능대체(Functional Replacement)가 가능한 회로 사양을 갖추고 있습니다. 데이터시트 상에는 일반 SOP-16과 방열 패드가 내장된 TSSOP-16(EP) 옵션이 존재하지만, 당사에서는 열 방출 성능이 월등히 뛰어난 **TSSOP-16(EP)** 패키지 사양인 **EUP2998XIR1**만 공급하고 있습니다.

## 1. EUP2998XIR1 핵심 특징

* **우수한 방열 성능의 TSSOP-16(EP) 패키지 단독 공급**: 하단에 바닥면 Exposed Thermal Pad(EP)가 내장되어 있어 기존 일반 패키지 대비 뛰어난 열 방출 특성을 자랑합니다.
* **넓은 입력 전압 범위 (V<SUB>IN</SUB>)**: 8V ~ 35V 지원 (Absolute Max 36V 스펙으로 안정적인 구동을 위해 입력전압 28V ~ 30V 이하로 설계 권장)
* **4채널 병렬 구동 및 강력한 출력 지원**:
  * 채널당 최대 25개의 LED 직렬 연결 지원 (총 4 스트링, 출력 전압 V<SUB>OUT</SUB> 최대 90V)
  * 채널당 최대 240mA 구동 능력 보유
* **8.5V 게이트 드라이버 내장**: 외부 N-채널 MOSFET을 효율적으로 제어하여 Boost 컨버터 변환 효율을 극대화합니다.
* **정밀한 채널 간 전류 매칭 오차**: $\pm 1.5\%$ 이하의 완성도 높은 LED Current Regulation 성능을 확보했습니다.
* **Direct PWM 및 Analog 디밍 모드 동시 지원**: 외부 PWM 신호를 내부에서 아날로그 디밍 신호로 변환하는 컨버터 회로를 내장하고 있습니다 (LPF 핀 활용).
* **시스템 보호 기능 (Full Fault Protections)**: Output Over-Voltage Protection (OVP), Current Limit, Output Short Protection, Over-Temperature Protection (OTP), LED Open/Short 감지

## 2. MP3398EGF vs EUP2998XIR1 주요 스펙 비교

MPS社의 MP3398EGF와 핀투핀(Pin-to-Pin) 호환이 가능하며 주요 스펙은 아래와 같습니다.

| 주요 사양 (Parameter) | MPS MP3398EGF | EUTECH EUP2998XIR1 (당사 공급) |
| :--- | :--- | :--- |
| **입력 전압 범위 ($V_{IN}$)** | 4.5V ~ 33V | 8V ~ 35V (입력마진 감안하여 입력전압 28V ~ 30V 까지 사용권장) |
| **채널당 LED 구동 전류** | 최대 400mA | 최대 240mA |
| **최대 출력 전압 ($V_{OUT}$)** | 최대 80V | 최대 90V (더 넓은 LED 스트링 구성 가능) |
| **Current Regulation 오차** | $\pm 2.30\%$ | $\pm 1.50\%$ (더 우수한 채널 균일도) |
| **공급 패키지 (Package)** | TSSOP-16(EP) | TSSOP-16(EP) |

## 4. 대표 응용 회로도 및 핀 배치 (Application & Pinout)

### ① 기본 응용 회로도 (Typical Application Circuit)
외부 MOSFET, 승압 인덕터, 다이오드 및 4채널 LED 스트링과 연결되어 최대 90V 출력을 형성하는 고효율 백라이트 회로입니다.

![EUP2998 회로도](https://github.com/juniorchu/juniorchu.github.io/blob/main/assets/EUP2998%20%ED%9A%8C%EB%A1%9C%EB%8F%84.png?raw=true)

### ② TSSOP-16(EP) 핀 배치도 (Top View)
* **1번 (CH1) / 2번 (CH2) / 4번 (CH3) / 5번 (CH4)**: LED 스트링 1~4번 전류 싱크 핀
* **3번 (GND)**: Ground (하단 Exposed Pad 역시 GND에 결합)
* **6번 (ISET)**: LED 풀스케일 전류 설정 저항 연결 핀
* **7번 (OVP)**: 출력 과전압 보호 피드백 핀
* **8번 (FSET)**: 스위칭 주파수 설정 저항 연결 핀 (예: $100\text{k}\Omega = 500\text{kHz}$)
* **9번 (EN)**: 칩 활성화 Enable 핀
* **10번 (ICS)**: 외부 인덕터 전류 감지 Current Sense 입력 핀
* **11번 (DRV)**: 외부 N-CH MOSFET 게이트 드라이버 출력 핀 (8.5V)
* **12번 (REG)**: 내부 5V 레귤레이터 바이패스 핀
* **13번 (VIN)**: 메인 입력 전원 공급 핀 (8V ~ 35V)
* **14번 (LPF)**: 디밍 모드 설정 핀 (REG 직결 시 Direct PWM, RC 연결 시 Analog 변환)
* **15번 (COMP)**: 루프 보상 및 Soft-Start 핀
* **16번 (PWMI)**: 밝기 제어 PWM 디밍 신호 입력 핀
