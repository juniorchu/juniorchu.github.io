# MT3886MFFR – MP8756 핀투핀 호환, 33V 입력 6A 동기식 Buck Converter


안녕하세요 M3TEK 국내 공식 대리점 (주)제이씨코포레이션 입니다.

소개드리고자 하는 **MT3886MFFR**은 M3 Technology의 33V 입력, 6A 출력 지원 동기식 Step-Down DC-DC Converter입니다.

DFN 2mm x 3mm 의 패키지를 지원하며, VFB가 0.6V로 낮아서 0.9V~1V CORE 전원 공급용으로도 적절합니다.

특히 기존 **MPS MP8756과 핀투핀 호환이 가능하며**, MP8756의 입력전압 범위보다 넓은 **4.5V~33V 입력전압**을 지원합니다.

두 제품은 6A 연속 출력전류, 700kHz 스위칭 주파수, QFN 2×3mm 12핀 패키지 등 주요 사양이 유사합니다. 기존 MP8756을 적용한 제품에서 입력전압 범위 확장이 필요하거나 대체 부품을 검토하는 경우 MT3886 검토 가능하십니다. 

## 1. MT3886 주요 특징

- 입력전압 범위: **4.5V~33V**
- 출력전압 범위: 0.6V~33V
- 최대 연속 출력전류: 6A
- 스위칭 주파수: 700kHz (Typ.)
- 제어 방식: Fast-PWM Constant On-Time(COT)
- Feedback Reference Voltage: 0.6V (±1%)
- 거의 100% Duty Cycle 지원
- PFM / Ultrasonic / Forced PWM 3가지 동작 모드중 선택 가능
- 내부 MOSFET 집적: HS 21mΩ / LS 10mΩ (MP8756 대비 우수)
- 보호 기능: UVLO, 입력 OVP, 출력 OVP, Cycle-by-Cycle Current Limit, Short-Circuit Hiccup, Thermal Shutdown
- 동작온도: -40°C~+85°C 
- 패키지: QFN 2×3mm 12L

MT3886의 주요 차별점은 기존 MP8756과 핀투핀 호환이 가능하면서 더 넓은 입력전압 범위를 지원한다는 것입니다.

## 3. Fast-PWM COT 제어 방식

MT3886은 M3 Technology의 Fast-PWM Constant On-Time(COT) 제어 방식을 적용했습니다.

COT 방식은 출력 피드백 전압이 기준 전압보다 낮아지면 High-Side MOSFET을 즉시 켜서 인덕터 전류를 증가시키는 방식으로 동작합니다.

출력 부하가 급격하게 변할 때 피드백 전압의 변화를 빠르게 반영할 수 있어, 기존의 고정 주파수 PWM 방식과 비교해 빠른 과도응답을 기대할 수 있습니다.

또한 700kHz의 일정한 스위칭 주파수를 유지하도록 설계되었습니다.

### 주요 제어 특성

- Fast transient response
- 700kHz switching frequency
- 내부 Ramp Compensation
- 저 ESR 세라믹 출력 커패시터 지원
- 별도의 외부 보상 네트워크 없이 안정적인 동작 가능

## 4. 3가지 동작 모드 선택

MT3886은 MODE 핀을 이용해 부하 조건과 시스템 요구사항에 맞는 동작 모드를 선택할 수 있습니다.

| MODE 핀 설정 | 동작 모드 | 주요 특성 |
|---|---|---|
| AGND 연결 | PFM | 경부하 효율 개선 |
| Floating (NC) | Ultrasonic Mode | 가청 주파수 대역의 스위칭 노이즈 회피 |
| VCC 연결 | Forced PWM | 전체 부하 범위에서 일정한 스위칭 주파수 유지 |

### 4-1. PFM Mode

경부하 조건에서 스위칭 주파수를 조절하여 불필요한 스위칭 손실을 줄이는 모드입니다. 대기전류 및 경부하 효율이 중요한 애플리케이션에 적합합니다.

### 4-2. Ultrasonic Mode (UAM)

MODE 핀을 Floating 상태로 설정하면 Ultrasonic Mode로 동작합니다.

- 경부하시 PWM 모드로만 동작하는(FORCED PWM 모드) 경우보다 효율이 개선되는 효과
- 부하가 적게 걸릴 때 가청주파수 대역에서 스위칭 주파수가 동작하는 PFM 모드에 비해,
  스위칭 주파수가 최소 35KHz로 동작함으로써 가청 주파수 대역에서 발생할 수 있는 스위칭 노이즈를 개선가능

### 4-3. Forced PWM Mode

MODE 핀을 VCC에 연결하면 Forced PWM 모드로 동작합니다.

경부하에서도 일정한 스위칭 주파수를 유지해야 하는 시스템에서 검토할 수 있습니다.

## 5. 거의 100% Duty Cycle 지원

MT3886은 거의 100% Duty Cycle 동작을 지원합니다.

입력전압과 출력전압의 차이가 작아지는 조건에서도 높은 듀티비로 동작할 수 있어, 입력전압이 출력전압에 가까운 시스템에서 유용합니다.

데이터시트의 전기적 특성에는 VIN=5V, VOUT=5V 조건에서 최대 듀티비 99.5%가 기재되어 있습니다.

다만 실제 출력전압은 입력전압, 부하전류, 인덕터 및 내부 스위치의 전압 강하 등에 영향을 받으므로 설계 시 충분한 입출력 전압차를 고려해야 합니다.

## 6. 내부 MOSFET 및 보호 기능

MT3886은 High-Side 및 Low-Side MOSFET을 내부에 집적하여 외부 부품 수를 줄일 수 있습니다.

| 항목 | Typical Value |
|---|---:|
| High-Side MOSFET RDS(ON) | 21mΩ |
| Low-Side MOSFET RDS(ON) | 10mΩ |
| Feedback Reference Voltage | 0.6V |
| Soft-Start Time | 1.8ms |
| Switching Frequency | 700kHz |

### 보호 기능

- **UVLO:** 입력전압이 정상 동작 조건보다 낮아지는 경우 IC 보호
- **Input OVP:** 입력 과전압 보호
- **Output OVP:** 출력 과전압 보호
- **Cycle-by-Cycle Current Limit:** 주기별 전류 제한
- **Short-Circuit Hiccup:** 지속적인 과부하 또는 출력 단락 조건에서 Hiccup 방식 보호
- **Thermal Shutdown:** 내부 온도 상승 시 IC 보호

또한 Power Good(PG) 핀을 통해 출력전압의 정상 상태 여부를 외부 시스템에 전달할 수 있습니다.

## 7. 주요 적용 분야

MT3886은 넓은 입력전압 범위와 6A 출력전류를 요구하는 다양한 전원 회로에 적용할 수 있습니다.

- USB Type-A / Type-C 전원 회로 (USB TYPE-C 용 회로 첨부 데이터시트에서 확인 가능)
- USB PD Dongle 및 Docking Station
- Tablet PC
- Networking System
- Flat Panel TV 및 Monitor
- Distributed Power System

특히 24V 전원 시스템이나 기존 MP8756 적용 회로에서 입력전압 범위를 확장해야 하는 경우 검토할 수 있습니다.

### 8-1. 입력 커패시터

입력 커패시터는 VIN과 PGND 핀 가까이에 배치하여 입력 전류에 의한 전압 스파이크와 노이즈를 줄여야 합니다.

데이터시트의 설계 가이드에 따라 X5R 또는 X7R 계열 세라믹 커패시터를 사용하고, DC Bias 및 온도에 따른 실제 유효 정전용량을 고려해야 합니다.

### 8-2. 인덕터 선정

인덕터 리플 전류는 최대 출력전류의 약 30~50% 수준을 기준으로 설계할 수 있습니다.

인덕터의 포화전류는 최대 부하 및 전류 제한 조건에서 포화되지 않도록 충분한 여유를 확보해야 합니다.

### 8-3. 출력 커패시터

출력 커패시터는 출력 리플 및 부하 과도응답 요구사항에 따라 선정해야 합니다.

X5R 또는 X7R 계열 세라믹 커패시터를 사용할 수 있으며, USB Type-C 및 PD 관련 회로처럼 출력전압이 높은 애플리케이션에서는 커패시터의 정격전압과 DC Bias 특성을 특히 주의해야 합니다.

### 8-4. PCB Layout

고속 스위칭 DC-DC Converter는 PCB Layout이 회로의 안정성과 발열에 큰 영향을 줍니다.

- VIN, SW, 인덕터, 출력 커패시터로 이어지는 고전류 경로를 짧고 넓게 설계
- 입력 커패시터를 VIN 및 PGND 핀 가까이에 배치
- SW 노드 배선 길이를 최소화
- SW 노드와 FB 신호 배선 간격 확보
- VCC 바이패스 커패시터를 VCC 및 AGND 핀 가까이에 배치
- BST와 SW 사이의 부트스트랩 회로 배선을 짧게 설계
- VIN 및 GND 주변에 충분한 Copper 면적과 Via 확보
- 가능하면 4-Layer PCB 적용 검토
