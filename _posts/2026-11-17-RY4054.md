# RY4054AT5 – LTC4054-4.2 Pin-to-Pin 대체 가능한 4.2V 리튬이온 배터리 충전 IC

## 1. 제품소개

**RY4054AT5**는 RYCHIP에서 공급하는 단일 셀 리튬이온 배터리용 Linear Charger IC입니다.

기존에 널리 사용되는 **LTC4054-4.2과 핀투핀 호환되는 SOT23-5 패키지** 제품으로, 기존 LTC4054 기반 충전 회로의 대체 부품을 검토하는 엔지니어에게 적합한 후보입니다.

RY4054AT5는 CC/CV(Constant Current / Constant Voltage) 충전 방식을 사용하며, 외부 저항 하나로 충전 전류를 설정할 수 있습니다.

내부 Power MOSFET과 Thermal Regulation 회로를 내장하고 있어 별도의 외부 MOSFET이나 전류 감지 저항 없이 간단한 충전 회로를 구성할 수 있습니다.

다만, **RY4054는 TRICKLE 기능이 있는 제품만** 양산 하므로, 이점 참조 부탁 드립니다.

주요 적용 분야는 다음과 같습니다.

- 휴대용 전자기기 및 소형 IoT 기기
- Bluetooth 기기 및 무선 액세서리
- 웨어러블 디바이스
- 충전 크래들 및 Charging Dock
- USB 전원을 사용하는 단일 셀 리튬이온 배터리 충전 회로

## 2. 주요 특징 (Key Features)

- 단일 셀 리튬이온 배터리 충전 IC
- 정전류 / 정전압 방식(CC/CV) 충전 지원
- 4.2V 고정 충전 전압
- 외부 저항을 통한 충전 전류 설정 (최대 500mA)
- 약 120°C 열 조절 기능 (Thermal Regulation)
- 자동 재충전 기능 (Automatic Recharge)
- C/10 충전 종료 기능
- 2.9V 트리클 충전 진입 전압 (Trickle Charge Threshold)
- 오픈 드레인 방식 충전 상태 출력 (CHRG)
- 내부 P채널 전력 MOSFET 내장
- 외부 전류 검출 저항 불필요
- 외부 역류 방지 다이오드 불필요
- 소프트 스타트 기능 (Soft-Start)
- 저전압 잠금 기능 (UVLO)
- 셧다운 전류: 일반값 25µA
- SOT23-5 패키지

## 5. Charging Current Programming

<figure align="center" style="text-align: center;">
  <img src="https://juniorchu.github.io/assets/RY4054회로도.png" alt="RY4054 TYPICAL APPLICATION CIRCUIT">
  <figcaption > ▲ RY4054 회로도</figcaption>
</figure>

RY4054AT5는 PROG 핀과 GND 사이에 연결하는 외부 저항 RPROG를 이용하여 충전 전류를 설정합니다.

**충전 전류 설정식**

- RPROG (kΩ) = 1000 / ICHG (mA)
- ICHG (mA) = 1000 / RPROG (kΩ)

대표적인 설정값은 다음과 같습니다.

| RPROG | Charging Current |
|---:|---:|
| 20kΩ | 50mA |
| 10kΩ | 100mA |
| 5kΩ | 200mA |
| 2.5kΩ | 400mA |
| 2kΩ | 500mA |

※ 위 값은 데이터시트의 전류 설정 관계를 이용한 계산값입니다. 실제 충전 전류는 입력 전압, 배터리 전압 및 IC의 온도 제한 동작에 영향을 받습니다.

## 6. CC/CV Charging Operation

RY4054AT5는 단일 셀 리튬이온 배터리를 충전하기 위한 CC/CV 방식을 지원합니다.

<figure align="center" style="text-align: center;">
  <img src="https://juniorchu.github.io/assets/RY4054FLOWCHART.png" alt="RY4054 STATE DIAGRAM">
  <figcaption > ▲ RY4054 동작방식</figcaption>
</figure>

<br>

**1) Trickle Charge Mode**

배터리 전압이 약 2.9V 미만인 경우 Trickle Charge Mode로 동작합니다.

이때 설정된 충전 전류의 약 1/10 수준으로 충전하여 배터리 전압을 정상 충전 영역까지 상승시킵니다.

**2) Constant Current Mode**

배터리 전압이 2.9V를 초과하면 설정된 충전 전류를 공급하는 Constant Current Mode로 진입합니다.

PROG 저항을 통해 설정된 충전 전류가 배터리에 공급됩니다.

**3) Constant Voltage Mode**

배터리 전압이 최종 충전 전압인 4.2V에 접근하면 Constant Voltage Mode로 전환됩니다.

배터리 전압을 일정하게 유지하면서 충전 전류는 점차 감소합니다.

**4) Charge Termination**

충전 전류가 설정 충전 전류의 1/10(C/10) 수준까지 감소하면 충전이 종료됩니다.

충전 종료 후에는 Standby Mode로 진입하며, 배터리 전압이 재충전 기준 전압인 약 4.05V 이하로 떨어지면 자동으로 새로운 충전 사이클을 시작합니다.

## 7. Thermal Regulation

Linear Charger IC에서 중요한 설계 요소 중 하나는 IC의 발열입니다.

RY4054AT5는 내부 Thermal Regulation 회로를 통해 Junction Temperature가 약 120°C에 도달하려고 할 때 충전 전류를 자동으로 감소시킵니다.

Linear Charger의 내부 발열은 다음과 같은 관계로 결정됩니다.

- PD = (VCC - VBAT) × IBAT

예를 들어 입력 전압이 5V이고 배터리 전압이 3.7V인 상태에서 500mA로 충전한다면 IC에서 발생하는 대략적인 전력 손실은 다음과 같습니다.

- PD = (5V - 3.7V) × 0.5A
- PD = 0.65W

따라서 최대 500mA 충전 전류를 설정하더라도 실제 충전 전류는 PCB의 방열 성능과 주변 온도에 따라 감소할 수 있습니다.

최대 충전 전류를 활용하려면 PCB Copper Area와 GND 패턴을 포함한 열 설계를 충분히 고려해야 합니다.

## 8.추가 보호 및 제어기능

**Automatic Recharge**

충전 종료 후 배터리 전압을 지속적으로 모니터링합니다. 배터리 전압이 약 4.05V 이하로 떨어지면 자동으로 충전을 재시작합니다.

**Undervoltage Lockout (UVLO)**

입력 전압이 UVLO 기준보다 낮으면 충전 동작을 중단하여 비정상적인 입력 전압 조건에서 IC를 보호합니다.

**Soft-Start**

충전이 시작될 때 충전 전류를 약 100µs 동안 점진적으로 증가시켜 전원 입력단의 돌입 전류를 줄입니다.

**CHRG Status Output**

CHRG 핀은 Open-Drain 방식의 충전 상태 출력입니다.

- 충전 중: CHRG 핀 Pull-Down
- 충전 종료 후: CHRG 핀 High Impedance

외부 LED 등을 연결하여 충전 상태를 표시할 수 있습니다. LED 구동 시에는 외부 전류 제한 저항이 필요합니다.

## 9. LTC4054-4.2 대체 검토

LTC4054-4.2는 Analog Devices의 대표적인 단일 셀 리튬이온 배터리 충전 IC입니다.

RY4054AT5는 LTC4054-4.2와 동일한 핀 배열 및 기본적인 CC/CV 충전 구조를 가지고 있어 기존 설계의 대체 후보로 검토할 수 있습니다.

두 제품간의 비교표는 아래 참조 부탁 드리며, 보다 자세한 전기적 특성등의 차이점은 각 제조사 데이터시트 참조 부탁 드립니다. 


| Parameter | RY4054AT5 | LTC4054-4.2 |
|---|---:|---:|
| Manufacturer | RYCHIP | Analog Devices |
| Package | SOT23-5 | ThinSOT / TSOT23-5 |
| Pin Configuration | 1:1 동일 | 1:1 동일 |
| Charging Voltage | 4.2V | 4.2V |
| Maximum Charge Current | 500mA | 800mA |
| Trickle Charge Threshold | 2.9V | 2.9V |
| Charge Termination | C/10 | C/10 |
| Thermal Regulation | Approximately 120°C | Approximately 120°C |
| Automatic Recharge | Yes | Yes |


※ RY4054AT5는 TRICKLE 기능을 지원하는 제품만 양산 중입니다.

## 10. Applications

RY4054AT5는 외부 부품 수가 적고 회로 구성이 간단한 Single Cell Li-Ion Battery Charger IC입니다.

특히 5V USB 전원을 이용하는 소형 전자기기 및 저전류 배터리 충전 회로에 적합합니다.

주요 적용 분야:

- Bluetooth Headset
- Wireless Audio Devices
- Wearable Devices
- Portable Electronic Products
- Charging Dock and Cradle
- USB Powered Battery Charging Circuit
- Single Cell Li-Ion Battery Charging Applications
