# [MT3035NDCR] 2.5V~5.5V 입력 4A 연속 / 5A 피크 1.5MHz Synchronous Buck DC/DC Converter | RT8068A, RT8078A, SY20218 핀투핀 대체

MT3035는 2.5V~5.5V 입력 전압에서 동작하며, 4A 연속 출력 전류와 5A 피크 전류를 지원하는 1.5MHz 동기식 Buck Converter입니다.

MT3035NDCR의 주요 특징은 다음과 같습니다.

- **입력 전압:** 2.5V ~ 5.5V
- **연속 출력 전류:** 4A
- **피크 출력 전류:** 5A
- **출력 전압:** 0.6V ~ VIN
- **스위칭 주파수:** 1.5MHz
- **제어 방식:** Proprietary Fast Transient COT (Constant On-Time)
- **피드백 기준 전압:** 0.6V ±2%
- **최대 효율:** 95%
- **대기 전류(Quiescent Current):** 15µA (Typical)
- **100% Duty Cycle 동작 지원**
- **내장 MOSFET:** High-Side 80mΩ / Low-Side 50mΩ
- **Soft-Start:** 내부 1ms 사용하거나 외부 커패시터로 설정 가능
- **보호 기능:** Cycle-by-Cycle Current Limit, Overload 및 Short Circuit Hiccup Mode, Thermal Shutdown
- **Power Good:** Open-Drain Output
- **Output Discharge 기능**
- **패키지:** DFN3x3-10L

특히 빠른 부하 과도 응답 특성을 제공하는 COT 제어 방식과 15µA의 낮은 대기 전류는 MT3035의 주요 장점입니다.

## 3. MT3035의 주요 기술적 장점

### 3-1. COT 제어 방식으로 빠른 Load Transient Response

MT3035는 Proprietary Fast Transient Constant On-Time(COT) 제어 방식을 채택했습니다.

일반적인 고정 주파수 PWM 방식과 달리, COT 제어 방식은 출력 전압이 피드백 기준 전압보다 낮아지는 상황에서 빠르게 스위칭 동작을 시작할 수 있습니다.

이를 통해 부하 전류가 급격하게 변하는 Load Transient 조건에서 빠른 응답 특성을 확보할 수 있습니다.

또한 MT3035는 부하 전류에 따라 On-Time을 적응적으로 조절하는 Proprietary Adaptive On-Time 기술을 적용하여 넓은 부하 범위에서 비교적 일정한 스위칭 주파수를 유지하도록 설계되었습니다.

### 3-2. 100% Duty Cycle 지원

MT3035는 100% Duty Cycle 동작을 지원합니다.

일반적인 Buck Converter에서는 입력 전압과 출력 전압의 차이가 작아질수록 요구되는 Duty Cycle이 높아집니다.

이때 100% Duty Cycle 동작을 지원하면 입력 전압이 출력 전압에 근접하는 조건에서도 High-Side MOSFET을 연속적으로 도통시켜 출력 전압을 유지할 수 있습니다.

따라서 입력 전압 변동 폭이 크거나 입력 전압과 출력 전압의 차이가 작은 전원 설계에서 검토할 수 있습니다.

### 3-3. 낮은 Quiescent Current와 경부하 효율

MT3035의 Quiescent Current는 Typical 15µA입니다.

부하가 적을 때는 Discontinuous Conduction Mode(DCM)로 동작하면서 대기 전류를 낮게 유지하여 효율 개선에 유리합니다.

배터리 구동 장치나 대기 시간이 긴 전자기기처럼 경부하 소비전력이 중요한 설계에서 검토할 수 있습니다.

### 3-4. 내장 Soft-Start 및 다양한 보호 기능

MT3035는 기본적으로 내부 1ms Soft-Start 기능을 제공합니다.

또한 SS 핀에 외부 커패시터(CSS)를 연결하면 원하는 Soft-Start 시간을 추가로 설정할 수 있습니다.

Soft-Start 시간은 다음과 같이 결정됩니다.

TSS = MAX (1ms, 0.6V × CSS / 2µA)

주요 보호 기능은 다음과 같습니다.

- Cycle-by-Cycle High-Side Current Limit
- Overload Protection
- Short Circuit Hiccup Mode
- Thermal Shutdown Protection
- Output Discharge

특히 과부하 또는 출력 단락 상태가 지속되면 Hiccup Mode로 진입하며, 일정 시간 후 자동으로 재시동을 시도합니다. 재시동 시에는 Soft-Start가 다시 적용됩니다.

### 4-1. Richtek RT8068A / RT8078A 대체 검토

RT8068A 및 RT8078A를 사용하고 있는 기존 설계에서 MT3035로의 대체를 검토할 수 있습니다.

주요 검토 포인트는 다음과 같습니다.

- 동일한 DFN3x3-10L 계열 패키지
- MT3035 내부 1ms Soft-Start 기본 제공하므로, RT8068A, RT8078A NC핀과 사실상 핀투핀으로 사용 가능합니다.
- 연속 4A 및 피크 5A 출력 전류 지원



### 4-2. Silergy SY20218 대체 검토

SY20218과 MT3035는 동일한 핀 배치를 갖는 제품으로 검토할 수 있습니다.

다만 출력 전류 사양에는 차이가 있습니다.

- SY20218: 6A
- MT3035: 4A Continuous / 5A Peak

따라서 SY20218을 사용하던 설계에서 MT3035로 변경할 경우 실제 부하 전류와 인덕터 피크 전류, 발열 조건 등을 확인해야 합니다.

특히 기존 회로가 5A를 초과하는 연속 출력 조건이라면 MT3035로의 대체는 적합하지 않을 수 있습니다.

### 4-3. Silergy SY20215 대체 시 주의사항

SY20215는 MT3035와 패키지 크기가 동일하지만 핀 배치에 차이가 있습니다.

다음 3개 핀의 연결을 확인해야 합니다.

| Pin Number | SY20215 | MT3035 |
|---|---|---|
| Pin 1 | NC | SW |
| Pin 3 | NC | SW |
| Pin 7 | NC | SS |
