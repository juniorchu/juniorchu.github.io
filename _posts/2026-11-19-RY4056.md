# [RYCHIP 국내 공식 대리점] RY4056 (RY4056AP8) - TP4056 핀투핀(Pin-to-Pin) 호환 1A 리튬이온 배터리 충전 IC


## 1. 제품 소개

**RY4056AP8은 TP4056 ESOP8과 동일한 1~8번 핀 배열을 제공하는 1A 단일 셀 리튬이온 배터리 충전 IC입니다.**

RY4056은 Constant Current / Constant Voltage(CC/CV) 충전 방식을 사용하는 선형 리튬이온 배터리 충전 IC로, 별도의 외부 MOSFET이나 전류 감지 저항 없이 간단한 충전 회로를 구성할 수 있습니다.

특히 RY4056AP8은 TP4056 ESOP8과 핀 배열이 동일하여 기존 TP4056 기반 충전 회로에서 대체 가능성을 검토할 수 있습니다.

다만 핀 배열이 동일하더라도 입력 전압 범위, 충전 전류 설정 저항, 열 제한 온도 및 대기 전류 등 전기적 특성에는 차이가 있으므로 회로 변경 전 데이터시트 비교가 필요합니다.

## 2. 주요 특징

- 단일 셀 리튬이온 배터리 충전 IC
- Constant Current / Constant Voltage (CC/CV) 충전 방식
- 외부 저항을 통한 충전 전류 설정
- 최대 충전 전류 1000mA
- 충전 전압 4.2V
- C/10 충전 종료 감지 기능
- 자동 재충전 (Automatic Recharge)
- Thermal Regulation을 통한 과열 보호
- 2.9V Trickle Charge Threshold
- 충전 상태 표시 기능 (CHRG)
- 배터리 온도 감지 기능 (TEMP)
- 내부 P-Channel Power MOSFET
- 외부 전류 감지 저항 불필요
- 외부 Blocking Diode 불필요
- Reverse Battery Protection
- Soft-Start 기능
- ESOP8 및 DFN6-2×2 패키지 지원

## 3. 주요 적용분야(Applications)

- 휴대용 전자기기
- 블루투스 기기
- 웨어러블 기기
- 충전 도크 및 크래들
- USB 전원 기반 배터리 충전기
- 단일 셀 리튬이온 배터리 충전 회로

## 4. 핀배열(Pin Configuration) - RY4056AP8 vs TP4056 ESOP8

RY4056AP8(SOP-8)은 TP4056 ESOP8과 **핀투핀(Pin-to-Pin) 호환성을 갖는 제품**입니다.

| Pin | RY4056AP8 | TP4056 ESOP8 | Function |
|---|---|---|---|
| 1 | TEMP | TEMP | Battery Temperature Detection |
| 2 | PROG | PROG | Charge Current Programming |
| 3 | GND | GND | Ground |
| 4 | VCC | VCC | Input Supply Voltage |
| 5 | BAT | BAT | Battery Charging Output |
| 6 | STDBY | STDBY | Charge Completion Indicator |
| 7 | CHRG | CHRG | Charge Status Output |
| 8 | EN | CE | Chip Enable |

### 4.1 주요 호환성 확인 사항

- 1~7번 핀은 동일한 명칭과 기능을 사용합니다.
- 8번 핀은 RY4056에서 EN, TP4056에서 CE로 표기되어 있습니다. (기능 동일)
- 두 제품 모두 High 입력에서 정상 동작하고 Low 입력에서 충전을 금지하는 Enable 제어 방식입니다.
- RY4056AP8의 9번 EPAD는 GND에 연결됩니다. PCB 설계 시 노출 패드의 접지 및 방열 연결을 확인해야 합니다.

## 5. 충전 동작 (Charging Operation)

RY4056은 CC/CV(Constant Current / Constant Voltage) 충전 알고리즘을 사용합니다.

### 5.1 Trickle Charge Mode

배터리 전압이 2.9V 미만인 경우 Trickle Charge Mode로 동작합니다.

이때 충전 전류는 설정된 충전 전류의 약 1/10 수준으로 공급되어 배터리 전압을 정상 충전 구간까지 올립니다.

### 5.2 Constant Current (CC) Mode

배터리 전압이 2.9V를 초과하면 Constant Current Mode로 진입합니다.

PROG 핀에 연결된 저항에 의해 설정된 충전 전류를 배터리에 공급합니다.

### 5.3 Constant Voltage (CV) Mode

배터리 전압이 4.2V에 도달하면 Constant Voltage Mode로 전환됩니다.

충전 전압은 4.2V로 유지되며, 배터리 충전 전류는 점차 감소합니다.

충전 전류가 설정 전류의 1/10 수준까지 감소하면 충전이 종료됩니다.

### 5.4 자동재충전(Automatic Recharge)

충전 완료 후 배터리 전압이 약 4.05V 이하로 떨어지면 RY4056은 자동으로 충전을 재개합니다.

## 6. 충전전류 설정

RY4056은 PROG 핀과 GND 사이에 연결하는 외부 저항으로 충전 전류를 설정합니다.

충전 전류와 설정 저항의 관계는 다음과 같습니다.

R<sub>PROG</sub> (kΩ) = 1000 / I<sub>CHG</sub> (mA)


충전 전류 설정 예시는 다음과 같습니다.

| R<sub>PROG</sub> | 충전전류 설정값 |
|---:|---:|
| 10kΩ | 100mA |
| 2kΩ | 500mA |
| 1kΩ | 1000mA |


## 7. Thermal Regulation

RY4056은 내부 Thermal Regulation 기능을 지원합니다.

충전 중 IC의 접합 온도가 약 120°C에 도달하면 충전 전류를 자동으로 조절하여 IC의 온도 상승을 제한합니다.

Linear Type이여서 열이 많이 발생할 수 있으므로, 최대 충전전류인 1A의 80% 선까지 설정하는 것을 권해 드립니다.

## 8. 충전 상태 표시 (Charge Status Indicator)

RY4056은 CHRG 핀을 통해 충전 상태를 표시할 수 있습니다.

CHRG 핀은 Open-Drain 방식이며 데이터시트에는 다음과 같은 출력 상태가 명시되어 있습니다.

- Strong Pull-Down: 충전 진행 중
- Weak Pull-Down: 충전 종료 후 입력 전원 조건이 충족되어 충전 대기 상태
- High Impedance: 입력 전압 및 UVLO 조건 등에 따른 상태

이를 이용하여 외부 LED 등의 충전 상태 표시 회로를 구성할 수 있습니다.

ESOP8 패키지에서는 STDBY 핀도 제공하며 충전 완료 상태를 표시하는 데 사용할 수 있습니다.

## 9. RY4056AP8 vs TP4056 ESOP8 -주요사양 비교

RY4056AP8과 TP4056은 핀 배열뿐 아니라 기본 충전 방식과 주요 기능도 유사합니다.

그러나 세부 전기적 특성에는 차이가 있습니다.

| Parameter | RY4056AP8 | TP4056 |
|---|---:|---:|
| Package | ESOP8 | ESOP8 |
| Pin Configuration | 1~8 Pin | 1~8 Pin |
| Charging Method | CC/CV | CC/CV |
| Maximum Programmed Charge Current | 1000mA | 1000mA |
| Preset Charge Voltage | 4.2V | 4.2V |
| Input Voltage Range | 4.25V ~ 6.5V | 4.0V ~ 8.0V |
| Trickle Charge Threshold | 2.9V | 2.9V |
| Charge Termination | C/10 | C/10 |
| Thermal Regulation Temperature | 120°C | 145°C |
| Standby Supply Current (Typ.) | 200µA | 55µA |
| Shutdown Supply Current (Typ.) | 25µA | 55µA |
| Automatic Recharge | Yes | Yes |

※ 위 비교는 각 제조사 데이터시트에 기재된 사양을 기준으로 작성했습니다. 전기적 특성의 측정 조건은 제품별 데이터시트를 확인해야 합니다.

### 9.1 입력전압 범위

RY4056의 권장 입력 전압 범위는 4.25V~6.5V이며, TP4056은 데이터시트의 전기적 특성표에서 4.0V~8.0V로 명시되어 있습니다.

따라서 TP4056을 사용하는 기존 회로의 입력 전압이 6.5V를 초과한다면 RY4056으로 대체하기 전에 입력 전압 조건을 반드시 확인해야 합니다.

### 9.2 충전전류 설정 저항값

두 제품은 충전 전류 설정에 사용하는 저항값이 다릅니다.

- RY4056: RPROG(kΩ) = 1000 / ICHG(mA)
- TP4056: RPROG(kΩ) = 1100 / ICHG(mA)

예를 들어 1A 충전 전류를 설정하는 경우 다음과 같습니다.

| Device | RPROG for 1A |
|---|---:|
| RY4056 | 1kΩ |
| TP4056 | 1.1kΩ |

따라서 TP4056에서 사용하던 충전 전류 설정 저항을 그대로 사용하는 경우 실제 충전 전류가 달라질 수 있으므로 저항값을 재검토해야 합니다.

### 9.3 Thermal Regulation

RY4056의 Thermal Regulation 온도는 약 120°C이며, TP4056은 약 145°C입니다.

두 제품의 열 제한 동작 조건에 차이가 있으므로 높은 충전 전류를 사용하는 설계에서는 PCB 방열 성능과 실제 동작 온도를 확인해야 합니다.

### 9.4 Standby Supply Current

충전이 완료된 Standby Mode에서의 입력 전원 전류는 다음과 같습니다.

- RY4056: Typical 200µA
- TP4056: Typical 55µA

따라서 배터리 충전 완료 후에도 입력 전원이 계속 연결되는 제품에서는 대기 전류 차이를 고려해야 합니다.
